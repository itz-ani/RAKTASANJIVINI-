# 🩸 Rakta Sanjivani - Real-Time Blood Management Platform

Rakta Sanjivani is a **MedTech platform** designed to bridge the gap between hospitals, blood banks, donors, and patients. By replacing manual, phone-based coordination with a **data-driven digital network**, we provide **real-time visibility** and **faster response times** during medical emergencies in India.

---

## ✨ Key Features

- **Real-Time Dashboard:** Live visibility of blood unit availability across registered facilities.  
- **GPS Locator:** Find the nearest blood center with the specific blood group you need.  
- **Emergency SOS:** One-click requests that notify nearby hospitals and eligible donors instantly.  
- **Smart Notifications:** Alerts for donors (eligibility/urgency) and hospitals (low stock/shortage risks).  
- **AI-Based Prediction:** Forecast upcoming shortages using historical trends with Power BI analytics.  
- **Secure Communication:** Dedicated panel for coordination between hospitals and blood banks.

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)  
- MySQL Server  
- npm or yarn  

### Installation

1. **Clone the repository**

```bash
git clone https://github.com/itz-ani/RAKTASANJIVINI-Blood-Management-System-.git
cd RAKTASANJIVINI-Blood-Management-System-

```

2. **Setup Frontend**

 ```bash
 cd Frontend
npm install
# Create a .env file with your DB credentials & API keys
npm run dev
```

3.**Setup Backend**

```bash
cd backend
node server.js
```
